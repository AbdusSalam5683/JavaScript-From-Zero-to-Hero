# JavaScript: From Zero to Hero 🚀

**শুরুর তারিখ:** ২০ অক্টোবর, ২০২৬  
**প্রত্যাশিত সমাপ্তি:** জুন ২০২৭ (৬ মাস)

| **১. ফাউন্ডেশন** | অক্টো – ডিসে ২০২৬ | সিনট্যাক্স, লজিক, DOM | ৩টি বেসিক প্রজেক্ট |
| **২. ইন্টারমিডিয়েট** | জানু – মার্চ ২০২৭ | ES6+, Async/Await, API | ৩টি API-ভিত্তিক প্রজেক্ট |

## 📚 বিস্তারিত সিলেবাস

### ধাপ ১: ফাউন্ডেশন (Foundation)
- [ ] ভ্যারিয়েবল, ডেটা টাইপ, টাইপ কনভার্সন
- [ ] অপারেটর এবং কন্ডিশনাল স্টেটমেন্ট
- [ ] লুপ (for, while, do-while)
- [ ] ফাংশন (ডিক্লারেশন, এক্সপ্রেশন, অ্যারো)
- [ ] অ্যারে ও অবজেক্ট (বেসিক মেথড)
- [ ] DOM সিলেকশন ও ম্যানিপুলেশন
- [ ] ইভেন্ট লিসেনার
- [ ] **প্রজেক্ট:** ক্যালকুলেটর, টু-ডু লিস্ট

### ধাপ ২: ইন্টারমিডিয়েট (Intermediate)
- [ ] ES6+ ফিচার (let/const, ডিস্টラクচারিং, স্প্রেড)
- [ ] ক্লোজার এবং হায়ার-অর্ডার ফাংশন
- [ ] `this` কীওয়ার্ড
- [ ] প্রমিজ এবং async/await
- [ ] Fetch API ও JSON
- [ ] এরর হ্যান্ডলিং (try/catch)
- [ ] **প্রজেক্ট:** ওয়েদার অ্যাপ, গিথুব প্রোফাইল ফাইন্ডার

### ধাপ ৩: অ্যাডভান্সড (Advanced)
- [ ] OOP (ক্লাস, ইনহেরিটেন্স)
- [ ] মডিউল সিস্টেম (import/export)
- [ ] npm এবং বান্ডলার (Vite)
- [ ] টেস্টিং (Vitest/Jest)
- [ ] **ক্যাপস্টোন প্রজেক্ট:** আপনার পছন্দের একটি ফুল-স্ট্যাক অ্যাপ্লিকেশন
