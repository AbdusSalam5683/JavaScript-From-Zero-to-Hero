## 🎯 এই ক্লাসের উদ্দেশ্য

এই ক্লাসটি আপনার জাভাস্ক্রিপ্ট যাত্রার প্রথম ধাপ। এই ক্লাস শেষ করার পর আপনি নিম্নলিখিত বিষয়গুলোতে সক্ষম হবেন:

1. **জাভাস্ক্রিপ্ট কী এবং কেন এটি শিখবেন** — ভাষার ইতিহাস, ব্যবহারক্ষেত্র এবং গুরুত্ব বুঝতে পারবেন।
2. **ডেভেলপমেন্ট এনভায়রনমেন্ট সেটআপ** — VS Code, ব্রাউজার DevTools এবং Git সঠিকভাবে কনফিগার করতে পারবেন।
3. **প্রথম জাভাস্ক্রিপ্ট কোড লেখা** — ব্রাউজার কনসোলে এবং HTML ফাইলে জাভাস্ক্রিপ্ট রান করতে পারবেন।
4. **কোড এক্সিকিউশন বোঝা** — জাভাস্ক্রিপ্ট কীভাবে ব্রাউজারে কাজ করে তার মৌলিক ধারণা পাবেন।
5. **গিথুব রিপো স্ট্রাকচার তৈরি** — আপনার "JavaScript: From Zero to Hero" রিপোর প্রাথমিক ফোল্ডার স্ট্রাকচার তৈরি করবেন।

## 📋 যা জানা প্রয়োজন (Prerequisites)

এই ক্লাস শুরু করার আগে আপনার নিম্নলিখিত বিষয়গুলো থাকা/জানা আবশ্যক:

### ✅ আবশ্যক (Must Have)
- **একটি কম্পিউটার** (Windows/Mac/Linux) যাতে ইন্টারনেট সংযোগ আছে।
- **একটি আধুনিক ব্রাউজার** (Google Chrome সুপারিশকৃত)।
- **একটি টেক্সট এডিটর** (VS Code সুপারিশকৃত)।
- **একটি গিথুব অ্যাকাউন্ট** (আপনার ইতিমধ্যে আছে, যেহেতু রিপো খুলেছেন)।
- **বেসিক কম্পিউটার লিটারেসি** — ফাইল তৈরি, ফোল্ডার তৈরি, টার্মিনাল/কমান্ড প্রম্পট খোলা ইত্যাদি।

### 💡 সহায়ক (Good to Have, কিন্তু বাধ্যতামূলক নয়)
- HTML এবং CSS-এর প্রাথমিক ধারণা (শুধু বেসিক ট্যাগ চেনা)।
- ইংরেজিতে মৌলিক পড়ার ক্ষমতা (ডকুমেন্টেশন পড়ার জন্য)।
- Git-এর প্রাথমিক ধারণা (কমিট, পুশ)।

### ❌ যা জানার প্রয়োজন নেই
- আগের কোনো প্রোগ্রামিং অভিজ্ঞতা।
- গণিত বা অ্যালগরিদমের গভীর জ্ঞান।
- কোনো ফ্রেমওয়ার্ক বা লাইব্রেরির জ্ঞান।

## 🧠 জাভাস্ক্রিপ্ট কী? (থিওরি)

### সংক্ষিপ্ত পরিচয়
জাভাস্ক্রিপ্ট (JS) হলো একটি **হাই-লেভেল, ইন্টারপ্রেটেড, ডায়নামিক প্রোগ্রামিং ভাষা** যা মূলত ওয়েব ব্রাউজারে ইন্টারঅ্যাকটিভ ওয়েবসাইট তৈরির জন্য ব্যবহৃত হয়। বর্তমানে এটি শুধু ব্রাউজারেই সীমাবদ্ধ নয় — সার্ভার (Node.js), মোবাইল অ্যাপ (React Native), ডেস্কটপ অ্যাপ (Electron) এবং গেম ডেভেলপমেন্টেও ব্যবহৃত হয়।

### কেন জাভাস্ক্রিপ্ট শিখবেন?
| কারণ | ব্যাখ্যা |
|------|----------|
| **ওয়েবের ভাষা** | যেকোনো ওয়েবসাইটের ইন্টারঅ্যাকটিভ অংশ জাভাস্ক্রিপ্ট দিয়ে তৈরি। |
| **চাকরির বাজার** | বিশ্বের সবচেয়ে চাহিদাসম্পন্ন প্রোগ্রামিং ভাষাগুলোর একটি। |
| **শেখা সহজ** | সিনট্যাক্স তুলনামূলক সহজ এবং দ্রুত ফলাফল দেখা যায়। |
| **বহুমুখী** | ফ্রন্টএন্ড, ব্যাকএন্ড, মোবাইল, ডেস্কটপ — সব জায়গায় ব্যবহারযোগ্য। |
| **বিশাল কমিউনিটি** | সমস্যা সমাধানের জন্য অসংখ্য রিসোর্স ও ফোরাম রয়েছে। |

### সংক্ষিপ্ত ইতিহাস
- **১৯৯৫:** Brendan Eich ১০ দিনে জাভাস্ক্রিপ্ট তৈরি করেন (তখন নাম ছিল Mocha, পরে LiveScript)।
- **১৯৯৭:** ECMAScript 1 স্ট্যান্ডার্ড প্রকাশিত হয়।
- **২০০৯:** ES5 প্রকাশ, যা আধুনিক জাভাস্ক্রিপ্টের ভিত্তি।
- **২০১৫:** ES6 (ES2015) — বড় আপডেট, যেখানে `let/const`, অ্যারো ফাংশন, ক্লাস ইত্যাদি যোগ হয়।
- **বর্তমান:** প্রতি বছর নতুন ফিচার যোগ হচ্ছে (ES2026 পর্যন্ত)।

> ⚠️ **গুরুত্বপূর্ণ নোট:** জাভাস্ক্রিপ্ট এবং জাভা দুটি সম্পূর্ণ আলাদা ভাষা। নামের মিল ছাড়া কোনো সম্পর্ক নেই।

## 🛠️ ধাপে ধাপে পরিবেশ সেটআপ

### ধাপ ১: VS Code ইনস্টল করা

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) এ যান।
2. আপনার অপারেটিং সিস্টেম অনুযায়ী ডাউনলোড করুন।
3. ইনস্টল শেষে VS Code খুলুন।

**প্রয়োজনীয় এক্সটেনশন ইনস্টল করুন (Extensions প্যানেল থেকে):**
- **Live Server** (Ritwick Dey) — HTML ফাইল লাইভ রিলোডের জন্য।
- **Prettier - Code formatter** — কোড অটো-ফরম্যাটের জন্য।
- **JavaScript (ES6) code snippets** — দ্রুত কোড লেখার জন্য।
- **Bracket Pair Colorizer** (বা VS Code-এর বিল্ট-ইন ব্র্যাকেট কালারাইজেশন)।

### ধাপ ২: Google Chrome এবং DevTools

1. Chrome ইনস্টল করা না থাকলে [https://www.google.com/chrome/](https://www.google.com/chrome/) থেকে ইনস্টল করুন।
2. যেকোনো পেজে রাইট-ক্লিক করে **Inspect** এ ক্লিক করুন, অথবা `F12` / `Ctrl+Shift+I` (Windows) বা `Cmd+Option+I` (Mac) চাপুন।
3. **Console** ট্যাবে ক্লিক করুন — এখানেই আমরা প্রথম জাভাস্ক্রিপ্ট কোড লিখব।
